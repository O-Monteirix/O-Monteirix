I'm João, a technology entrepreneur, software engineer and business leader.

- **Business Solutions:** ERP, CRM, retail management and financial systems.
- **Mobile Development:** building applications for Android and cross-platform environments.
- **Infrastructure & DevOps:** managing Linux servers, databases, Docker environments and deployments.
